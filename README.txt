THE 90 — Professional Football Information Portal

Stack: HTML5 + CSS3 + JavaScript
Pages: Home, Matches, Standings, Teams, Club Profiles, Players, Global, News, Article

The site is designed as a professional football-information front end with a static 2026/27 data snapshot.
Current fixture and standings snapshots are sourced from official Premier League / UEFA pages and cross-checked with current reporting.

Important: a truly live global football database requires a football-data API/backend. This project is structured so the static data objects in script.js can later be replaced with API responses without rebuilding the UI.
