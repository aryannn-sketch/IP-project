# THE 90 — Professional Football Information Portal

A modern, responsive football information web application providing comprehensive coverage of leagues, fixtures, standings, teams, and player profiles.

## 🚀 Features

- **Match Center**: Fixtures, live scores, and match results.
- **League Standings**: Up-to-date league tables with form indicators and statistics.
- **Club Profiles**: Dedicated pages for clubs with squad details and history.
- **Player Profiles**: Comprehensive player statistics and biographical data.
- **Global Coverage & News**: Football headlines, breaking news, and in-depth articles.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**

## 📁 Project Structure

```text
├── index.html       # Homepage / Dashboard
├── matches.html     # Fixtures and Results
├── standings.html   # League Tables
├── teams.html       # Teams Directory
├── club.html        # Club Profile View
├── players.html     # Players Directory
├── player.html      # Individual Player Profile
├── global.html      # Global Football Coverage
├── news.html        # News Portal
├── article.html     # Article Detail View
├── style.css        # Core Stylesheet
└── script.js       # App Logic & Static Data Store
```

## ⚙️ Running Locally

Simply open `index.html` in any modern web browser or serve via Live Server / Edge debugger.
